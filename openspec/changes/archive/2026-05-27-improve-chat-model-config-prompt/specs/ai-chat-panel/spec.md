## ADDED Requirements

### Requirement: 未配置模型时输入交互检测
当用户尝试在聊天输入框输入或发送消息时，系统 MUST 检测大模型是否已配置（`apiBaseUrl`、`apiKey`、`modelName` 均非空）。若未配置，则展示悬浮提示引导用户前往设置。

#### Scenario: 输入框获焦时未配模型展示提示
- **WHEN** 用户点击或通过 Tab 键切换到聊天输入框使其获得焦点
- **AND** 大模型配置不完整（`apiBaseUrl`、`apiKey`、`modelName` 任一为空）
- **THEN** 系统在输入框上方展示悬浮提示框
- **AND** 输入框设为禁用状态（不可输入文字）
- **AND** 提示框内容包含说明文字和"前往设置"按钮

#### Scenario: 点击发送按钮时未配模型展示提示
- **WHEN** 用户点击"发送"按钮或按 Enter 键尝试发送消息
- **AND** 大模型配置不完整
- **THEN** 系统在输入框上方展示悬浮提示框（与获焦时相同的提示框）
- **AND** 不发送消息

#### Scenario: 已配置模型时不展示提示
- **WHEN** 用户点击输入框使其获得焦点或点击"发送"按钮
- **AND** 大模型配置完整
- **THEN** 不展示悬浮提示框
- **AND** 输入框正常可用
- **AND** 点击发送时正常发送消息

### Requirement: 悬浮提示框展示与交互
悬浮提示框 SHALL 以气泡形式展示在输入框上方，包含引导文字和操作按钮。

#### Scenario: 提示框内容
- **WHEN** 检测到未配置模型
- **THEN** 展示一个悬浮气泡，包含：
  - 警告图标或文字提示"尚未配置大模型"
  - 简短说明引导用户配置 API 连接信息
  - 一个"前往设置"按钮
- **AND** 气泡位置在输入框上方，视觉上关联输入区域

#### Scenario: 点击"前往设置"按钮
- **WHEN** 用户在悬浮提示框中点击"前往设置"按钮
- **THEN** 系统切换到设置 Tab
- **AND** 自动定位到"供应商"面板（Provider 配置区域）
- **AND** 消除悬浮提示框

#### Scenario: 提示框消除方式
- **WHEN** 悬浮提示框处于展示状态
- **THEN** 以下任一操作应消除提示框：
  - 用户点击"前往设置"按钮
  - 用户点击提示框外部区域
  - 用户切换到其他 Tab

### Requirement: 已配置模型后可正常使用聊天
当大模型已配置完成，聊天输入框 SHALL 恢复为正常可用状态。

#### Scenario: 配置后返回聊天可正常输入
- **WHEN** 用户在设置页面完成模型配置并手动切换回"AI聊天"Tab
- **AND** 输入框获得焦点
- **THEN** 不再展示悬浮提示框
- **AND** 输入框处于可用状态，用户可以正常输入和发送消息

## REMOVED Requirements

### Requirement: 点击 AI聊天 Tab 自动跳转到设置
**Reason**: 静默跳转对用户无感知，交互不友好。改为在用户实际尝试使用聊天输入时提示配置。
**Migration**: 点击 AI聊天 Tab 始终展示聊天页面；配置检测移至输入框获焦和发送时触发。

### Requirement: 保存配置后自动跳回 AI聊天 Tab
**Reason**: 自动跳转剥夺用户选择权。用户可能在设置页还有其他配置需要调整，不应强制跳走。
**Migration**: 保存配置后停留在当前页面不跳转；用户手动切换 Tab。
