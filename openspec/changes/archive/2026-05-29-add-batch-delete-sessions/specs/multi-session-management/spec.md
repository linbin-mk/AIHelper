## MODIFIED Requirements

### Requirement: 会话删除
系统 SHALL 支持通过侧边栏会话卡片的右键菜单删除单个会话，以及通过列表底部的垃圾桶按钮批量删除选中的会话。

#### Scenario: 删除单个会话
- **WHEN** 用户右键点击侧边栏某会话卡片，选择「删除」
- **THEN** 弹出确认对话框：「确定删除会话「{标题}」？」
- **AND** 用户确认后，该会话从侧边栏移除并从存储中永久删除
- **AND** 若当前正在查看该会话，自动跳转到最近活跃的会话或欢迎页

#### Scenario: 批量选择删除会话
- **WHEN** 用户点击侧边栏会话列表底部的垃圾桶按钮
- **THEN** 弹出对话框展示所有会话（带复选框），支持全选/取消全选
- **AND** 用户勾选会话后点击「确定」，选中的会话被永久删除
- **AND** 若活跃会话被删除，持久化活跃会话 ID 被清空，聊天区重置为欢迎页
