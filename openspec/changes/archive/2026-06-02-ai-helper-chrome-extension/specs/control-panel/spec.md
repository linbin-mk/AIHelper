## 新增需求

### 需求：点击工具栏图标打开侧边栏面板
用户点击插件工具栏图标时，系统应当在当前标签页上打开持久化的侧边栏面板。

#### 场景：在活跃标签页上打开侧边栏
- **WHEN** 用户在显示 `https://example.com` 的标签页上点击插件工具栏图标
- **THEN** 侧边栏面板在当前标签页右侧打开，覆盖页面内容

#### 场景：侧边栏在标签页切换时保持打开
- **WHEN** 用户打开侧边栏面板后切换到另一个标签页
- **THEN** 侧边栏面板保持打开并更新为显示新活跃标签页的信息

### 需求：面板显示当前页面 URL
系统应当在面板头部区域显示活跃标签页的 URL。

#### 场景：活跃标签页切换时 URL 更新
- **WHEN** 侧边栏面板打开且用户切换到 `https://example.com/products` 标签页
- **THEN** 面板头部显示 `当前目标: https://example.com/products`

#### 场景：页面导航时 URL 更新
- **WHEN** 侧边栏面板打开且用户从 `https://example.com` 导航到 `https://example.com/about`
- **THEN** 面板头部在 1 秒内更新显示新 URL

### 需求：面板显示 Cookie 概览
系统应当查询活跃标签页 URL 的 `chrome.cookies.getAll`，并显示包括总数和 Cookie 类型分类的摘要信息。

#### 场景：显示活跃标签页的 Cookie 数量
- **WHEN** 侧边栏面板在一个有 2 个会话 Cookie 和 1 个持久 Cookie 的页面上打开
- **THEN** 面板显示 `Cookie: 当前页面 3 个 Cookie (2 Session, 1 Persistent)`

#### 场景：标签页切换时 Cookie 数量更新
- **WHEN** 用户从有 3 个 Cookie 的标签页切换到有 0 个 Cookie 的标签页
- **THEN** 面板更新 Cookie 显示为 0 个

### 需求：面板显示请求头挟持状态
系统应当在面板中显示当前已配置的注入请求头列表（仅名称）。

#### 场景：列出已配置的请求头
- **WHEN** 用户已配置注入 `Authorization` 和 `X-Token` 请求头
- **THEN** 面板显示 `已挟持 Header: Authorization, X-Token`

#### 场景：未配置请求头
- **WHEN** 没有配置任何注入请求头
- **THEN** 面板显示 `已挟持 Header: 无`

### 需求：面板显示捕获的请求列表
系统应当按时间顺序（最新在前）渲染可滚动的请求列表，显示 HTTP 方法、URL 路径和状态码。

#### 场景：请求在面板中列出
- **WHEN** 当前页面发出 `GET /api/user`（200）和 `POST /api/login`（201）请求
- **THEN** 面板在请求列表中显示这两个请求及其方法、路径和状态码

#### 场景：请求列表溢出时滚动
- **WHEN** 捕获并显示超过 15 条请求
- **THEN** 请求列表区域垂直滚动，面板头部和底部保持固定

### 需求：面板有关闭按钮
系统应当在面板头部提供关闭按钮（✕），用于关闭侧边栏面板。

#### 场景：关闭按钮隐藏面板
- **WHEN** 用户点击面板头部的关闭按钮
- **THEN** 侧边栏面板从当前标签页关闭
