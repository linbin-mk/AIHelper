## ADDED Requirements

### Requirement: 批量删除选中的会话
系统 SHALL 在侧边栏会话列表底部提供批量删除入口，允许用户通过复选框选择多个会话并确认删除。

#### Scenario: 点击垃圾桶按钮弹出选择对话框
- **WHEN** 侧边栏会话列表存在至少一个会话卡片
- **THEN** 列表底部显示垃圾桶图标按钮
- **AND** 用户点击垃圾桶按钮后，弹出居中悬浮对话框
- **AND** 对话框标题区域显示「批量删除会话」标题
- **AND** 对话框内容区域展示所有会话列表，每行包含一个复选框和该会话的标题
- **AND** 对话框底部包含「确定」按钮和「取消」按钮

#### Scenario: 全选/取消全选
- **WHEN** 对话框顶部「全选」复选框被点击
- **THEN** 若当前非全选状态，所有会话复选框被勾选
- **AND** 若当前已全选状态，所有会话复选框被取消勾选
- **AND** 当用户手动取消任一会话复选框时，「全选」自动取消勾选
- **AND** 当用户手动勾选所有会话复选框时，「全选」自动勾选

#### Scenario: 确认删除选中的会话
- **WHEN** 用户在对话框中勾选一个或多个会话，点击「确定」按钮
- **THEN** 系统遍历删除所有被选中的会话
- **AND** 若被删除的会话中包含当前活跃会话，系统同步清空持久化的活跃会话 ID
- **AND** 若活跃会话被删除，聊天区切换为欢迎页
- **AND** 侧边栏会话列表刷新，已删除的会话不再显示
- **AND** 对话框关闭

#### Scenario: 未选中任何会话时点击确定
- **WHEN** 用户未勾选任何会话复选框，点击「确定」按钮
- **THEN** 系统不执行任何删除操作
- **AND** 对话框关闭

#### Scenario: 取消批量删除
- **WHEN** 用户在对话框中点击「取消」按钮或点击遮罩区域
- **THEN** 对话框关闭，不执行任何删除操作
- **AND** 会话列表和当前会话状态保持不变

#### Scenario: 会话列表为空时隐藏垃圾桶
- **WHEN** storage 中无任何会话记录
- **THEN** 会话列表底部不显示垃圾桶按钮

#### Scenario: 批量删除后活跃会话不恢复
- **WHEN** 批量删除的会话中包含当前活跃会话
- **THEN** 页面刷新或重新进入 panel 时不恢复任何旧会话
- **AND** 聊天区展示欢迎页
