# memory-card

## 新增需求

### 需求：记忆卡片在知识面板中展示
系统 SHALL 在知识面板中渲染一张"记忆"卡片，使用 `type: "memory"` 与普通知识卡片区分。记忆卡片在首次记忆生成时自动创建，用户可删除。

#### 场景：首次记忆生成时自动创建记忆卡片
- **当** AI 对话完成后触发记忆生成且 `ai_helper_memory_item` 不存在
- **则** 系统自动创建一个 type 为 "memory" 的记忆条目，存入 `chrome.storage.local`
- **且** 记忆卡片显示在知识列表最顶部（重新渲染列表后）

#### 场景：记忆卡片与普通知识卡片视觉区分
- **当** 知识面板中同时存在记忆卡片和普通知识卡片
- **则** 记忆卡片使用不同背景色/边框色（主题色紫色调）与普通卡片区分
- **且** 卡片上显示 🧠 图标或"记忆"标签标识

#### 场景：用户可删除记忆卡片
- **当** 用户点击记忆卡片的删除按钮并确认
- **则** 系统删除 `ai_helper_memory_item`
- **且** 同时清空该记忆卡片关联的所有记忆文件（IndexedDB 中 knowledgeId 匹配的文件和文件树）
- **且** 记忆卡片从知识列表中移除

#### 场景：删除后下次对话自动重建
- **当** 记忆卡片已被删除且用户完成新一轮 AI 对话
- **则** 系统在生成记忆时自动重新创建记忆卡片
- **且** 新记忆文件存入重建的卡片中

#### 场景：记忆卡片仅有一张
- **当** 系统生成记忆时已存在 memory 类型的条目
- **则** 复用已有记忆卡片，不创建新卡片
- **且** 如果意外存在多个 memory 类型条目，仅保留第一个，合并其余

### 需求：记忆卡片展示文件和域名统计
记忆卡片 MUST 展示记忆文件总数和覆盖域名数。general 域名作为正式域名计入统计，与其他域名无差别对待。

#### 场景：记忆卡片显示文件统计
- **当** 记忆卡片渲染
- **则** 卡片元数据区域显示"记忆: N个文件 / M个域名"
- **且** general 域和其他域名（如 `makedaily.cn`、`github.com`）均计入域名数量

#### 场景：点击文件管理查看记忆文件
- **当** 用户点击记忆卡片的"文件管理"按钮
- **则** 系统打开文件管理弹窗，展示以域名分组的记忆文件树

#### 场景：为空时展示引导提示
- **当** 记忆卡片创建后尚无任何记忆文件
- **则** 卡片描述显示"暂无记忆，完成 AI 对话后将自动生成"

### 需求：记忆卡片使用专用存储 key
记忆卡片的元数据 SHALL 存储在 `chrome.storage.local` 中，key 为 `ai_helper_memory_item`，值为单对象（非数组）。记忆文件内容 MUST 通过 FileCacheManager 存储，knowledgeId 使用记忆卡片的 id。

#### 场景：读取记忆卡片元数据
- **当** 系统需要获取记忆卡片信息
- **则** 从 `chrome.storage.local` 读取 `ai_helper_memory_item` key
- **且** 返回 `{ id, displayName: "记忆", type: "memory", description, createdAt, fileCount }`

#### 场景：记忆文件存储在 IndexedDB 中
- **当** 系统需要读取/写入记忆文件
- **则** 使用 FileCacheManager 以 `{knowledgeId: <memoryItem.id>, path, content}` 格式操作
- **且** 使用 TreeCacheManager 以 memoryItem.id 保存/读取文件树

### 需求：buildMemoryHint 同时注入双域记忆提示
`buildMemoryHint()` 函数 SHALL 在构建记忆提示时，并行查询当前域名和 general 域名的记忆文件，在 system prompt 提示词中同时呈现两个域的记忆信息，引导 AI 根据用户问题性质自主选择查询范围。

#### 场景：双域均有记忆时注入完整提示
- **当** 当前域名 `makedaily.cn` 下有 3 条记忆，general 域名下有 5 条记忆
- **则** 提示词包含：
  - "当前域名 makedaily.cn 下有 3 条历史记忆：..."
  - "通用记忆中有 5 条跨域经验：..."
  - "强烈建议先调用 search_memories 查当前域名记忆，如果涉及通用方法/模式/经验，也可以调用 search_memories({domain: 'general'}) 查询通用记忆。"
- **且** 功能地图引导仅针对当前域名文件进行

#### 场景：仅当前域有记忆时注入单域提示
- **当** 当前域名有记忆文件但 general 域为空
- **则** 提示词仅包含当前域记忆信息（行为与现有一致）

#### 场景：仅 general 域有记忆时注入通用记忆提示
- **当** 当前域名无记忆文件（或当前域名为 general），但 general 域有记忆文件
- **则** 提示词包含："通用记忆中有 N 条跨域经验，建议调用 search_memories({domain: 'general'}) 查询"
- **且** 不返回 null

#### 场景：当前域名就是 general 时正常展示
- **当** 当前域名（如无标签页）为 general，general 域下有记忆文件
- **则** 提示词中列出 general 域下的记忆文件（此时当前域 = general 域，不重复列出）
- **且** 不触发"先查当前域"的优先级引导
